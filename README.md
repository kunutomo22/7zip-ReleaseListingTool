# 7zip-ReleaseListingTool
7zipのリリースノートを分かりやすいリスト形式で出力や閲覧ができるツールです。
## 使い方
1. Releaseの最新版を取得する。  
2. zipを展開する。
3. `7zip-ReleaseList.ps1`を実行する。  
  
この手順でリリース履歴一覧をCSV形式で取得できます。
### 必要最低限のもの
- Powershell 5.1以上
- このプロジェクトにある以下のファイルとフォルダ
    - `7zip-ReleaseList.ps1`
    - `Common`
    - `Setting.txt`
    - `Output`  
Outputフォルダは、リリースノートの出力先として使用されます。  
Setting.txtの設定に応じて不要になりますが、デフォルトの設定を使用するには必要です。
### ツールの設定について
`Setting.txt`を編集することで、出力するリリース履歴一覧ファイルの出力形式や文字コード、ファイルの拡張子を変更できます。  
詳細は`Setting.txt`の中にあるコメントを参照してください。
## ツールの仕様
とても実行時間が長くなってしまう訳でもないので、リリース履歴は全量取得にしています。  
もし要望があれば、リリース履歴の取得件数を制限する機能を追加することも検討します。
